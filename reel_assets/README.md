# Reel assets — "Viral AI trading bot" (power.ai-style)

Recreation of the viral `power.ai` Instagram carousel format (the "Chinese student
turned $0.90 into $408,292 / reverse-engineered with Claude" post), built with the
Higgsfield image/video models.

## Important: honest framing
The original post's numbers are fabricated (a ~45,000,000% return and a "100% win
rate" do not exist; the dashboard in the original literally says "SIMULATED"). These
assets deliberately **do not** reproduce those deceptive financial claims. The hook is
reframed as a debunk/explainer angle — same trend and aesthetic, but truthful:

- **Hook:** "I REVERSE-ENGINEERED THE VIRAL AI TRADING BOT"
- **Subhead:** "HERE'S WHAT'S ACTUALLY REAL"
