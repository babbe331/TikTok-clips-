How do I import my spreadsheets?
Save each spreadsheet as a .csv file (in Excel or Google Sheets: File → Download/Save As → CSV), then click Import spreadsheet(s). You can pick several files at once — hold Ctrl/⌘ while selecting. We'll look for columns named name, quantity (or qty/on hand), unit, price, cost, category, and low stock. Column order and capitalization don't matter.

After reading the files you'll choose what to do: Replace wipes the current inventory and loads only what's in your spreadsheets, or Add & update keeps what's there and updates matching items by name.
